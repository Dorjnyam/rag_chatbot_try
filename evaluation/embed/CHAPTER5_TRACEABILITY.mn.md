## Identity compatibility requirement

Шинэ `embedding_contract` нь provider, model, боломжтой бол revision, dimensions, preprocessing version, normalization convention, query/document compatibility-г canonical hash болгон хадгална. Ижил dimension-тэй өөр model эсвэл өөр preprocessing/normalization нь өөр embedding space болно. `VectorStore` contract зөрвөл upsert/retrieval-ийг зогсооно. Model revision runtime-д тохируулагдаагүй бөгөөд provider response нь зөвхөн `text-embedding-3-small` model ID өгсөн; нарийвчилсан immutable revision **unavailable**.

Хуучин хувилбарын config contract field-гүй бол legacy default-оор тааруулж унших backward compatibility хадгална. Шинэ config fingerprint-тэй коллекц contract metadata-гүй бол fail closed.
